# 📖 单词复习系统

艾宾浩斯记忆曲线单词复习工具 — 翻卡 / 拼写 / 选择题

词本共享，**每个学生一份独立档案**：学习进度、错题本、学习记录、每日任务都按学生分开保存，第二天切换回自己的名字就能接着背。

---


## 📖 使用指南

### 首次使用

1. 打开网页后，首页显示欢迎界面和学习统计
2. 先确认侧栏顶部（手机是底部导航「学生」）是**哪位学生**，其他人在「学生档案」里新建
3. 点击"开始背诵"进入学习
4. 支持三种模式：**翻卡** / **选择题** / **拼写**

### 👥 学生档案（一个学生一份记录）

- 侧栏顶部下拉框可直接切换学生；「学生档案」页面可新建、改名、删除
- 每名学生独立保存：学习进度、错题本（含错误次数）、学习记录、今日任务、每日任务量
- 切换学生后页面自动刷新，读到的就是这名学生自己的数据，互不累加
- 旧版本留下的全局数据（进度 / 错题 / 学习记录）首次运行会自动并入「默认学生」，不会丢
- 至少保留一名学生；删除学生时其全部记录一并清除
- 档案页会列出每名学生的今日已学、累计掌握、掌握率、错题数、连续天数，方便对比

### 🔄 同一台电脑开多个标签页

- 两个标签页同时开着同一个学生也能用：一边背词，另一边通过 `storage` 事件自动跟上进度和今日任务，不需要刷新
- 今日任务**以后写入者为准**，不会互相覆盖成两份不同的任务
- 切换 / 新建学生属于档案级变化，其他标签页会整页重载，避免读到上一个学生的数据
- 正在背的这一轮队列（顺序和你已经看到的词）不会被其他标签页打断，只同步计数和任务本身

### 📅 每日任务（三种模式抽查内容一致）

- 进入「开始背诵」时自动生成当天任务，默认 **33 词**，可在 5～100 之间调整
- 组队规则：**八成新词 + 两成近期回顾**（33 词 ≈ 26 新 + 7 回顾），回顾词从最近 3 天学过的词里挑，新旧均匀穿插；前一天没背完的词仍会按到期时间优先出现
- 翻卡、选择、拼写用的是**同一批词、同一个顺序**：
  - **翻卡**：正面直接显示单词 + 音标 + 释义，翻面看例句（背记内容）
  - **选择**：看英文认中文（四选一，先选中再确认）
  - **拼写**：看中文写英文
- 页面下方「今日单词一览」可展开当天这批词：英文 + 音标 + 释义 + 例句 + 发音，回顾词带「回顾」标签，适合整体过一遍或家长抽查
- 当天任务做完会弹出鼓励语：「恭喜你，完成一天任务，继续坚持！」再跟一句随日期变的附加语
- 打开「乱序抽查」后顺序会被打乱且当天固定，三种模式仍然对得上，适合互相抽查；关掉即回到任务原本顺序
- 「重新生成今日任务」按当前任务量重排一次；第二天自动换一批词

### 艾宾浩斯滚动复习

- 答对一次升一级，下次复习间隔按 **1 → 2 → 4 → 7 → 15 → 30 → 60 天**逐档拉长，Lv.7 之后稳定按 60 天滚动
- 答"模糊"：等级不升，30 分钟后重新出现
- 答"不认识"：等级回到 Lv.0，5 分钟后重新出现
- 模糊和不认识都会进错题本；同一天里同一个词重复答对不会连续升级，避免一遍就"掌握"

### 翻卡背诵

1. 卡片正面直接显示**单词 + 音标 + 中文释义**（不用先翻面就能看意思）→ 点击或按 **空格** 翻到背面看**语境例句**
2. 看到释义后，三选一评价：
   - **1 - 不认识**：5 分钟后重试
   - **2 - 模糊**：等级不升，30 分钟后复习
   - **3 - 认识**：提升等级，按艾宾浩斯曲线安排下次复习
3. 答"不认识 / 模糊"的词会被插回当天队列，同一轮里再练一次
4. 手机上支持手势：答案还没显示时，左右上下滑都只是**翻面**；答案显示后，**右滑=认识**、**左滑=不认识**、**下滑=模糊**，上滑不评分。桌面用键盘快捷键（1 / 2 / 3 / 空格）

### 选择题模式

看单词，从 4 个选项中选出正确的释义，选项优先取自当天任务的词。

- **先选中、后确认**：点选项只是选中，再点同一项可取消，确认之前不算答错、不进错题本
- 干扰项会优先挑**同词性、释义长度接近、与正确答案互不包含**的词，避免靠一眼排除法蒙对
- 答错本轮末尾再出一次，反馈里给出这个词的例句

### 拼写模式

看释义，打字输入对应的英文单词，自动判对错并发音；答错本轮末尾再出一次。

### 统计数据与分析

首页和统计页展示：

- 总单词数 / 已掌握 / 掌握率
- 今日已学（去重）/ 连续学习天数
- 今日任务完成进度（已完成 / 任务量）
- 单词掌握度分布图（Lv.0 ~ Lv.7）

统计页顶部标着当前学生和词本，底部是**写有学生名字的个性化分析**：当前词本掌握情况、今日任务完成度、剩余新词大约还要几天过完、错得最多的词、停在 Lv.1-2 和进入 Lv.5+ 的词数、以及针对连续天数的建议；同时给出**高频错词表**（错误次数 + 最近错误日期）。

## 🔐 管理员模式

> 单词管理功能默认对普通用户隐藏，只有管理员能操作。

**进入管理员模式：** 快速点击顶部标题 **"📖 单词复习"** 5 次

- 侧栏会出现"单词管理"菜单
- 底部出现"管理员"标签
- 可添加/删除词本、增删单词、批量导入、导出数据

**退出管理员模式：** 点击侧栏底部的"管理员"标签

> 管理员状态保存在当前浏览器的 localStorage 中，仅自己可见。

## ☁️ 数据说明

| 数据类型 | 存储位置 | 说明 |
|---------|---------|------|
| 词本 / 单词 | Supabase 云端（未配置时 localStorage） | 所有人共享，增删即时同步 |
| 学生名单 | localStorage `word_review_students` | 本机保存，仅这份浏览器可见 |
| 掌握等级 / 复习时间 | localStorage `wr_<学生id>_progress` | 每个学生一份 |
| 错题本 + 错误次数 | localStorage `wr_<学生id>_wrong` `_wrong_counts` | 每个学生一份 |
| 学习记录 / 连续天数 | localStorage `wr_<学生id>_records` | 每个学生一份 |
| 今日任务 / 每日任务量 | localStorage `wr_<学生id>_tasks` `_settings` | 每个学生一份，第二天自动换新 |

> 所有学习数据只存在**这台电脑的这个浏览器**里，不会上传；换设备或换浏览器看不到。多名学生共用一台电脑时，靠「切换学生」区分记录。

### 数据备份

单词管理（管理员模式）→ 数据管理 → **导出为 JSON**，生成的文件包含所有词本和单词。

发给别人 → 对方在相同页面点 **从 JSON 恢复**。

### 自测

```bash
npm run test:logic   # 逻辑自测：状态层 / 存储 / 每日任务 / 跨标签页同步（Node 环境，秒级）
npm run test:e2e     # 端到端自测：先 build，再用无头 Chrome/Edge 真点页面
npm test             # 两个都跑
```

- 逻辑自测在 Node 里用内存版 `localStorage` 模拟浏览器，覆盖取词、评分、错题、迁移、学生隔离、多标签页写入收敛、每日任务 8:2 配比、干扰项质量、688 词语境例句完整性、完成鼓励语（149 条断言）
- 端到端自测自带静态服务器，用 CDP 真点真滑：三种模式同源、错题本、统计刷新、学生切换与隔离、双标签页同步、移动端触屏滑动、乱序开关与今日单词一览、老种子词补例句、完成一天任务后的鼓励卡片（124 条断言）
- 找不到浏览器时用 `CHROME_BIN=/path/to/chrome npm run test:e2e` 指定
- 两者都要求 **Node 22+**（端到端自测用 Node 内置 `WebSocket` 直连 CDP，Node 20 没有；版本过低会直接报错退出）
- 两个自测都在 CI（`.github/workflows/test.yml`，Ubuntu + Node 22 + 自带 Chrome）里跑，push / PR 都会执行；失败时会把日志尾部写进 job summary 并上传截图

```

  components/      # 组件
  composables/     # 组合式函数（useTouchSwipe.js：翻卡触屏手势）
  utils/           # 工具（profile.js 学生档案与隔离存储；sync.js 跨标签页；distractors.js 干扰项；encouragement.js 鼓励语；defaultWords.json 688 词库）
tests/
  logic.test.mjs     # 逻辑自测（Node + 内存 localStorage）
  build-logic.mjs    # 把逻辑自测打成单文件（Vite 处理 src/ 的 import）
  browser.test.mjs   # 端到端自测（无头浏览器 + CDP）
  env.mjs            # 逻辑自测的浏览器环境替身
.github/workflows/
  deploy.yml       # push main 后构建并发布 gh-pages
  test.yml         # 逻辑 + 端到端自测
```

# 📖 单词复习系统

艾宾浩斯记忆曲线单词复习工具 — 翻卡 / 选择 / 拼写 / 完形 / 音节

默认词本是**中考必背2000英语词汇**（2009 词，导入自 2025 秋新课标中考词表），开箱就能按天背。

词本共享，**每个学生一份独立档案**：学习进度、错题本、学习记录、每日任务都按学生分开保存，第二天切换回自己的名字就能接着背。

## 📖 使用指南

### 首次使用

1. 打开网页后，首页显示欢迎界面和学习统计
2. 先确认侧栏顶部（手机是底部导航「学生」）是**哪位学生**，其他人在「学生档案」里新建
3. 点击"开始背诵"进入学习
4. 支持五种模式：**翻卡** / **选择** / **拼写** / **完形** / **音节**

### 👥 学生档案（一个学生一份记录）

- 侧栏顶部下拉框可直接切换学生；「学生档案」页面可新建、改名、删除
- 每名学生独立保存：学习进度、错题本（含错误次数）、学习记录、今日任务、每日任务量
- 切换学生后页面自动刷新，读到的就是这名学生自己的数据，互不累加
- 旧版本留下的全局数据（进度 / 错题 / 学习记录）首次运行会自动并入「默认学生」，不会丢
- 至少保留一名学生；删除学生时其全部记录一并清除
- 档案页会列出每名学生的今日已学、累计掌握、掌握率、错题数、连续天数，方便对比

### 🔄 同一台电脑开多个标签页

- 两个标签页同时开着同一个学生也能用：一边背词，另一边通过 `storage` 事件自动跟上进度和今日任务，不需要刷新
- 今日任务**以后写入者为准**，不会互相覆盖成两份不同的任务
- 切换 / 新建学生属于档案级变化，其他标签页会整页重载，避免读到上一个学生的数据
- 正在背的这一轮队列（顺序和你已经看到的词）不会被其他标签页打断，只同步计数和任务本身

### 📅 每日任务（五种模式抽查内容一致）

- 进入「开始背诵」时自动生成当天任务，默认 **40 词**，**在 5～200 之间随便调**（「每日任务量」输入框，当天立即按新数量重排）
- 组队规则：**八成新词 + 两成近期回顾**（40 词 ≈ 32 新 + 8 回顾），回顾词从最近 3 天学过的词里挑，新旧均匀穿插；前一天没背完的词仍会按到期时间优先出现
- 同一批任务里不会同时出现释义相同的两个词（例如 `a` / `an`），避免"答对了一个也算答对另一个"
- 翻卡、选择、拼写、完形、音节用的都是**同一批词、同一个顺序**：
  - **翻卡**：正面只有单词 + 音标（**不显示中文**），点一下＝听发音 + 翻面，背面看音节串和语境例句
  - **选择**：看英文认中文（四选一，先选中再确认），答对有音效、答错给 🤔 和正确答案
  - **拼写**：看中文写英文，**手写板**上写（可切换键盘），点「对答案」自己判对错
  - **完形**：句子里挖掉一个词，四选一填回去
  - **音节**：按音标切成音节，一个音节一个音节地念、记，先把当天这批词的骨架过一遍
- 当天任务做完会飘**烟花特效**，并弹出鼓励语：「恭喜你，完成一天任务，继续坚持！」再跟一句随日期变的附加语
- 打开「乱序抽查」后顺序会被打乱且当天固定，五种模式仍然对得上，适合互相抽查；关掉即回到任务原本顺序
- 「拼读音效」开关可一键关掉所有提示音（默认开）
- 「重新生成今日任务」按当前任务量重排一次；第二天自动换一批词

### 📖 今日单词表（中文释义都在这里）

复习页下方有两个入口：**今日单词表** 和 **100 词测试卷**（侧边栏也有）。

- 今日单词表把当天这批词摊成一张表：序号 / 单词（回顾词带「回顾」标签）/ 音标 / 音节 / 词性·释义 / 例句 / 🔊 发音
- 翻卡模式里不再显示中文，就是为了让学生先在「听音 + 看音节」里自己回忆，中文统一到这里对照
- 家长抽查、整体过一遍、抄写都用这张表

### 📄 100 词测试卷

- 从当前词本随机抽 **100 个词、打乱顺序**，看英文选中文，**一题 1 分**
- 可以来回翻页改答案，答过的题会高亮
- 交卷后飘烟花并播放完成音效，按分数评级：
  - **100 分 → Excellent**
  - **≥ 95 分 → Good**
  - **≥ 90 分 → Normal**
  - **< 90 分 → Come on**
- 成绩页会列出错词（单词 / 音标 / 正确释义），可以直接照着抄一遍再背
- 词本不足 100 词时有多少考多少，分数按题量折算成百分比评级

### 艾宾浩斯滚动复习

- 答对一次升一级，下次复习间隔按 **1 → 2 → 4 → 7 → 15 → 30 → 60 天**逐档拉长，Lv.7 之后稳定按 60 天滚动
- 答"模糊"：等级不升，30 分钟后重新出现
- 答"不认识"：等级回到 Lv.0，5 分钟后重新出现
- 模糊和不认识都会进错题本；同一天里同一个词重复答对不会连续升级，避免一遍就"掌握"

### 翻卡背诵

1. 卡片正面只有**单词 + 音标**，**没有中文**
2. **点一下卡片**：立刻朗读这个词，同时翻面（不用再去点喇叭）；背面显示单词、音标、**按音节切好的音标串**（如 `ə·'bɪ·lə·tɪ`）、语境例句
3. 翻面后三选一评价：
   - **1 - 不认识**：5 分钟后重试
   - **2 - 模糊**：等级不升，30 分钟后复习
   - **3 - 认识**：提升等级，按艾宾浩斯曲线安排下次复习
4. 答"不认识 / 模糊"的词会被插回当天队列，同一轮里再练一次
5. 手机上支持手势：答案还没显示时，左右上下滑都只是**翻面**；答案显示后，**右滑=认识**、**左滑=不认识**、**下滑=模糊**，上滑不评分。桌面用键盘快捷键（1 / 2 / 3 / 空格）

### 选择题模式

看单词，从 4 个选项中选出正确的释义。

- **先选中、后确认**：点选项只是选中，再点同一项可取消，确认之前不算答错、不进错题本
- **干扰项是故意挑难的**：优先**同一词性**（名词只跟名词比、动词只跟动词比），再按**释义里共用汉字、拼写形近、音标音近**打分挑选，跳过与正确答案释义互相包含的词，近期刚出现过的词降权——靠排除法蒙对越来越难
- 答对 / 答错都有音效；答错显示 🤔 和「再想想，正确答案是：」+ 正确释义
- **连对激励**：页头显示 `🔥 N 连对`，连对 3 题起逐级给称号并闪光、音效也随档位变高
  - 3 题 **Good** → 4 题 **Great** → 5 题 **Brilliant** → 6 题 **Wonderful** → 7 题 **Fantastic** → 8 题 **Excellent** → 9 题及以上 **Perfect**
- 答错本轮末尾再出一次，反馈里给出这个词的例句

### 完形填空（新）

- 从**今天这批词**里出题，不够就接最近 3 天见过的词，再不够才用整个词本兜底——所以基本都在背"昨天或今天刚见过"的词
- 干扰项也是同词性 + 易混淆那套，选项里不会出现一眼就能排除的凑数词
- 句子里挖掉目标词（含 `studied / studies` 这类变形），点选项即判对错，最多 12 题
- 答对同样计入连对激励，有音效与闪光

### 拼写模式

- 默认**手写**：在空白板上写出单词，点「对答案」看标准答案，然后自己点「写对了 / 写错了」；手写靠自评，不是 OCR 识别
- 想打字就点右上角「⌨️ 改用键盘」，键盘模式下回车即判对错并发音，点「✍️ 改用手写」可切回
- **拼写部分不显示音标**，避免靠音标"背形状"

### 🎵 音节背记（新：教怎么背单词）

- 按音标切音节，一个音节一个音节地教：`accomplish` → `ə·ˈkɒm·plɪʃ`
- 标出重音落在第几个音节，配合发音按钮一个音节一个音节地听
- 切分规则是"先找元音核，再按最大音节首分辅音"（`pl-` `str-` `tʃ` 这类辅音丛不拆开），全库 2009 条音标切完拼回去与原串一致
- 背长单词时先记音节骨架，再填字母，比死记字母顺序省力

### 🔔 音效与烟花

- 答对 / 答错 / 连对升级 / 完成任务都有提示音，全部是浏览器 **Web Audio 现场合成**（不下载任何音频文件，也没有版权问题）
- 连对档位越高，音高越高；答对是上行音，答错是低沉的短音
- 任务完成或测试卷满分时屏幕会飘**烟花**
- 不想出声就在「开始背诵」里把「拼读音效」关掉

### 统计数据与分析

首页和统计页展示：

- 总单词数 / 已掌握 / 掌握率
- 今日已学（去重）/ 连续学习天数
- 今日任务完成进度（已完成 / 任务量）
- 单词掌握度分布图（Lv.0 ~ Lv.7）

统计页顶部标着当前学生和词本，底部是**写有学生名字的个性化分析**：当前词本掌握情况、今日任务完成度、剩余新词大约还要几天过完、错得最多的词、停在 Lv.1-2 和进入 Lv.5+ 的词数、以及针对连续天数的建议；同时给出**高频错词表**（错误次数 + 最近错误日期）。

## 🔐 管理员模式

> 单词管理功能默认对普通用户隐藏，只有管理员能操作。

**进入管理员模式：** 快速点击顶部标题 **"📖 单词复习"** 5 次

- 侧栏会出现"单词管理"菜单
- 底部出现"管理员"标签
- 可添加/删除词本、增删单词、批量导入、导出数据

**退出管理员模式：** 点击侧栏底部的"管理员"标签

> 管理员状态保存在当前浏览器的 localStorage 中，仅自己可见。

## ☁️ 数据说明

| 数据类型 | 存储位置 | 说明 |
|---------|---------|------|
| 词本 / 单词 | Supabase 云端（未配置时 localStorage） | 所有人共享，增删即时同步；新装时自动种入「中考必背2000英语词汇」2009 词（只种一次，你删掉的词不会被塞回来） |
| 学生名单 | localStorage `word_review_students` | 本机保存，仅这份浏览器可见 |
| 掌握等级 / 复习时间 | localStorage `wr_<学生id>_progress` | 每个学生一份 |
| 错题本 + 错误次数 | localStorage `wr_<学生id>_wrong` `_wrong_counts` | 每个学生一份 |
| 学习记录 / 连续天数 | localStorage `wr_<学生id>_records` | 每个学生一份 |
| 今日任务 / 每日任务量 | localStorage `wr_<学生id>_tasks` `_settings` | 每个学生一份，第二天自动换新 |

> 所有学习数据只存在**这台电脑的这个浏览器**里，不会上传；换设备或换浏览器看不到。多名学生共用一台电脑时，靠「切换学生」区分记录。

### 数据备份

单词管理（管理员模式）→ 数据管理 → **导出为 JSON**，生成的文件包含所有词本和单词。

发给别人 → 对方在相同页面点 **从 JSON 恢复**。

### 自测

```bash
npm run test:logic   # 逻辑自测：状态层 / 存储 / 每日任务 / 跨标签页同步（Node 环境，秒级）
npm run test:e2e     # 端到端自测：先 build，再用无头 Chrome/Edge 真点页面
npm test             # 两个都跑
```

- 逻辑自测在 Node 里用内存版 `localStorage` 模拟浏览器，覆盖取词、评分、错题、迁移、学生隔离、多标签页写入收敛、每日任务 8:2 配比、干扰项质量、688 词语境例句完整性、完成鼓励语、音节切分、连对称号、测试卷评级与抽词、中考词表完整性（**206 条断言**）
- 端到端自测自带静态服务器，用 CDP 真点真滑：五种模式同源（翻卡 / 选择 / 拼写 / 完形 / 音节）、错题本、统计刷新、学生切换与隔离、双标签页同步、移动端触屏滑动、乱序开关、今日单词表整表可读、100 词测试卷全对得 Excellent、连对 3 题给 Good 闪光、老种子词补例句、完成一天任务后的鼓励卡片与控制台无 error；另有一整节按需求逐条断言（🤔 思考表情、完成放烟花、手写拼写、点卡即发音、干扰项同词性、音节背记、任务量可调、100 词测试卷评级、完形、音效开关、连对 7 档称号）（**327 条断言**）
- 找不到浏览器时用 `CHROME_BIN=/path/to/chrome npm run test:e2e` 指定
- 两者都要求 **Node 22+**（端到端自测用 Node 内置 `WebSocket` 直连 CDP，Node 20 没有；版本过低会直接报错退出）
- 两个自测都在 CI（`.github/workflows/test.yml`，Ubuntu + Node 22 + 自带 Chrome）里跑，push / PR 都会执行；失败时会把日志尾部写进 job summary 并上传截图

### 词表来源与重新生成

中考词表是零依赖解析 docx 得来的，脚本留在仓库里：

```bash
node scripts/parse-docx-vocab.mjs "C:/Users/<你>/Desktop/2025秋初中英语必背的2000个单词（新课标中考.docx"
```

输出 `src/utils/middleSchoolWords.json`（`{ word, phonetic, mean, sentence }`）。docx 里实际是 **2009** 条词条（原文件名写的 2000 是取整叫法），释义里有几十条因原文两栏排版被串在一起，属源头数据问题。
